# System Design социальной сети для курса по System Design
## Функциональные требования
1. Добавить пост
2. Оценить пост
3. Прокомментировать пост
4. Подписаться на путешественника
5. Просмотр ленты пользователя
6. Просмотр ленты на основе подписок
7. Просмотр популярных мест и постов с этих мест
## Нефункциональные требования
1. DAU - 10 000 000
2. Аудитория - СНГ
3. Активность пользователя
   1. 30 дней отпуска * 10 постов в день = 300 постов в год
   2. 10 реакций в неделю
   3. 5 комментариев в неделю
   4. 30 подписок в год
   5. Просмотр своей ленты 100 раз в год
   6. Просмотр подписок 2 раза в неделю
   7. Просмотр популярных мест 20 раза в год
4. Лимиты
   1. Размер фотографии до 30 Мб
   2. Максимальная длинна комментария/поста 2000 символов
   3. Максимум комментариев 1000
   4. Максимум реакций 10000
   5. Фотография после обработки весит не более 600Кб
5. Сезонность
   1. Сезон отпусков
6. Тайминги
   1. Добавить пост - 3 сек
   2. Оценить пост - 0,5 сек
   3. Прокомментировать пост - 1 сек
   4. Подписаться на путешественника - 0,5 сек
   5. Загрузка ленты - 2 сек
# Модель данных
1. Пост
   1. ID
   2. Дата
   3. Фото
   4. Координаты (Место)
   5. Пользователь
   6. Текст
2. Реакции
   1. ID
   2. Дата
   3. Пост
   4. Пользователь
   5. Реакция
3. Комментарий
   1. ID
   2. Дата
   3. Автор
   4. Пост
   5. Текст
4. Подписка
   1. ID
   2. Кто
   3. На кого
   4. Дата

# Нагрузка
1. Посты
   1. RPS (write) = 10 000 000 * 300 / 365 / 24 / 60 / 60 = 95
   2. RPS (read) = (10 000 000 * (100 + 2 * 52 недели + 20)) / 365 / 24 / 60 / 60 = 71
   3. Трафик (write) = 95 * 610Кб =  58 Мб/c
   4. Трафик (read) = 71 * 20 * 610Кб =  901 Мб/c
2. Реакции
   1. RPS (write) = 10 000 000 * 20 * 52 недели / 365 / 24 / 60 / 60 = 329
   2. RPS (read) = RPS (read) постов = 71
   3. Трафик (write) = 329 * 1Кб =  329 Кб/c
   4. Трафик (read) = 71 * 20 * 1Кб =  1,4 Мб/c
3. Комментарии
   1. RPS (write) = 10 000 000 * 5 * 52 / 365 / 24 / 60 / 60 = 82
   2. RPS (read) = RPS (read) постов = 71
   3. Трафик (write) = 82 * 3Кб = 246 Кб/c
   4. Трафик (read) = 71 * 5 * 20 * 3Кб =  21 Мб/c
4. Подписки
   1. RPS (write) = 10 000 000 * 30 / 365 / 24 / 60 / 60 = 9
   2. RPS (read) = 10 000 000 * 2 * 52 / 365 / 24 / 60 / 60 = 33
   3. Трафик (write) = 9 * 1Кб = 9 Кб/c
   4. Трафик (read) = 33 * 1Кб =  33 Кб/c
