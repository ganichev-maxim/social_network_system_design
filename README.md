# System Design социальной сети для курса по System Design
## Функциональные требования
1. Добавить пост
2. Оценить пост
3. Прокомментировать пост
4. Подписаться на путешественника
5. Просмотр ленты пользователя
6. Просмотр ленты на основе подписок
7. Просмотр популярных мест и постов с этих мест
## Нефункциональные требования
1. DAU - 10 000 000
2. Аудитория - СНГ
3. Активность пользователя
   1. 30 дней отпуска * 10 постов в день = 300 постов в год
   2. 50 реакций в неделю
   3. 5 комментариев в неделю
   4. 30 подписок в год
   5. Просмотр своей ленты 100 раз в год
   6. Просмотр подписок 2 раза в неделю
   7. Просмотр популярных мест 20 раз в год
   8. В среднем при просмотре лент пользователь обновляет ленту 10 раз
4. Лимиты
   1. Размер фотографии до 30 Мб. Фотография после обработки весит не более 200Кб
   2. Максимальная длинна комментария/поста 2000 символов
   3. Максимум комментариев в день 200
   4. Максимум реакций в день 200
   5. Фотография после обработки весит не более 200Кб
   6. На одной странице 20 постов
5. Сезонность
   1. Сезон отпусков
6. Тайминги
   1. Добавить пост - 3 сек
   2. Оценить пост - 0,5 сек
   3. Прокомментировать пост - 1 сек
   4. Подписаться на путешественника - 0,5 сек
   5. Загрузка ленты - 2 сек
# Модель данных
Модель данных в папке database.
Файлы хранятся в объектном хранилище

# Нагрузка
1. Посты
   1. RPS (write) = 10 000 000 * 300 / 365 / 24 / 60 / 60 = 95
   2. RPS (read) = (10 000 000 * (100 + 2 * 10 * 52 недели + 20 * 10)) / 365 / 24 / 60 / 60 = 424
   3. Трафик (write) медиа = 95 * 200Кб * 10 =  185 Мб/c
   4. Трафик (read)  медиа = 424 * 20 * 200Кб =  1,7 Гб/c
   5. Необходимое место (capacity) = 185 Мб/c * 86400 * 365 = 5564 Тбайт
   6. Трафик (write) данные = 95 * 4Кб =  380 Кб/c
   7. Трафик (read)  данные = 424 * 20 * 4Кб =  33 Мб/c
   8. Необходимое место (capacity) = 380 Кб/c * 86400 * 365 = 11.16 Тбайт
   9. Дисков по месту (HDD) = 5575 Тбайт / 32 Тбайт = 174 шт
   10. Дисков по месту (SSD SATA) = 5575 Тбайт / 100 Тбайт = 56 шт
   11. Дисков по месту (SSD nVME) = 5575 Тбайт / 30 Тбайт = 186 шт
   12. Дисков по пропускной способности (HDD) = 186 Мб/c / 100 Мб/c = 2 шт
   13. Дисков по пропускной способности (SSD SATA) = 186 Мб/c / 500 Мб/c = 1 шт
   14. Дисков по пропускной способности (SSD nVME) = 186 Мб/c / 3 Гб/c = 1 шт
   15. Дисков по IOPS (HDD) = 519 * 2 / 100 = 11 шт
   16. Дисков по IOPS (SSD SATA) = 519 * 2 / 1000 = 2 шт
   17. Дисков по IOPS (SSD nVME) = 519 * 2 / 10000 = 1 шт
   18. Итого дисков HDD 174, SSD SATA 56, NVME 186
